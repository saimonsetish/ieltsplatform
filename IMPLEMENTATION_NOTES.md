# IELTS Hub interaction update

This bundle contains a complete source snapshot with the learner–tutor submission and feedback flow changes plus PRODUCT_FLOW.md.

## Included changes
- Documented the core learner/tutor loop and submission states.
- Added a tutor queue with status filters and learner overview.
- Added autosaved tutor review drafts, rubric validation, feedback delivery, and skill-specific revision requests.
- Added learner My work with statuses, rubric feedback, revision/resubmission, and earlier-attempt history.
- Added learner response drafts saved in the current browser.
- Added responsive styles for the new review flow.

## Prototype boundary
Data still lives in localStorage and is shared only when both roles use the same browser profile. This bundle does not add account authentication, cross-device sharing, audio recording/upload, or private production data storage.
